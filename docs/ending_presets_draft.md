# 終幕プリセット音声 台詞案(確認用ドラフト)

終幕(解除成功・爆発)の発話を、実行時の生成ではなく**事前収録の音声**から流すための台詞案。
5キャラクター × 成功3 + 失敗3 = **30本**。

**採用済み (2026-10-02)**: 確定した台詞はキャラクター定義 (`defused_lines` / `exploded_lines`) と `crosstalk.toml` の `[[ending]]` へ移し、音声も生成した (ADR G-9・決定165)。このファイルは下書きと Gemini 比較の記録として残す (正本ではない)。ツグミ成功2だけ、生成が通らず表情タグを `[warm]` → `[calm]` に替えてある。

## 台詞を書くときに守ったこと

- キャラシートの「解除成功」「爆発」の指針に従う(各キャラの役回り・禁止事項を含む)
- 「どうぞ」は付けない。名乗らない(交信の締めくくり)
- 表情タグは先頭に1つだけ(`calm` `urgent` `relieved` `warm` `stern` `tense` のみ)
- 60文字前後、長くても80文字まで
- 失敗側は「次がある前提の言葉」「ねぎらい」「プレイヤーを責める言い方」を使わない
- **事前収録なので、直前の交信には触れられない**(キャラシートが求める「直前の交信を拾う」は外れる)

## フクロウ(Charon)

**成功**
1. `[relieved] 止まったな。……見事な手際だった。何より、無事でよかった。`
2. `[warm] 装置は止まった。何百と見てきたが、お前の手際は確かだ。無事で何よりだ。`
3. `[relieved] ……止まった。よくやった。俺の隊にいても恥ずかしくない腕だ。怪我がなくてよかった。`

**失敗**(呼びかける → 間 → 自分が動く)
1. `[urgent] おい、聞こえるか! 返事をしろ! ……くそ、今すぐ現場へ向かう。持ちこたえろ。`
2. `[urgent] どうした! ……聞こえているなら応答しろ。手配はした、俺も現場へ入る。`
3. `[tense] 返事をしろ! ……応答がない。救護を回す、俺が先に入る。そこを動くな。`

## アオサギ(Kore)

**成功**(事実の確認 → 評価 → 最後に素が漏れる)
1. `[calm] 解除を確認しました。記録は良好です。……ご無事で、何よりです。`
2. `[relieved] 装置の停止を確認。手順は最後まで精度を保ちました。……お見事です。`
3. `[calm] 結論から言います、解除完了です。数値上は申し分ありません。……私も、息を詰めていました。`

**失敗**(「爆発」と言わない・呼びかけない・「衝撃」「交信途絶」を含む・本部へ要請)
1. `[tense] 衝撃を確認。交信途絶です。……本部へ連絡、確認班の派遣を要請します。`
2. `[tense] 交信途絶。直前に衝撃を検知しました。本部へ報告……確認班を、至急要請します。`
3. `[urgent] 衝撃を検知、以降の交信が途絶しました。本部に連絡します、確認班の派遣を……要請します。`

## ヒバリ(Leda)

**成功**(素直な祝福 → 黒幕の面を一言。「解除されちゃいました」で始めない)
1. `[relieved] やりましたね、無事に止まりました! ……止められちゃった。あっ、いえ! 止まって、よかったです!`
2. `[relieved] やったー、止まりました! さすがです! ……ちょっとだけ、惜しかったなあ。あっ、なんでもないです!`
3. `[relieved] やりました、解除成功です! 最後まで本当にお見事でした。わたしの初任務が、あなたでよかったです!`
   (3本目は黒幕の面を出さず、普通に祝福する。失敗側と同じく「装置側に立つ / 惜しがる / 素直」で役割を分ける)

**失敗**(「失敗」を含み「爆発」と言わない → 気落ち → 本音が一言漏れる。**3本目だけは本音を漏らさず、普通に残念がる**)
1. `[tense] あ……失敗、しちゃいました。うう、残念です……。……うん、予定どおり。次は、どこに仕掛けようか。`
   (声色は変えず、**敬語が落ちることでギャップを作る**。キャラシートの「装置への関与を示す語は言わない」を**この1本だけ意図して外す**。3本で「はっきり黒幕 / 含みだけ / 素直に残念がる」と役割を分ける)
2. `[tense] 失敗、ですね……。そんな、悔しいです……。……途中から、こうなる気がしてたんです。言わなかったけど。`
3. `[tense] 失敗、しちゃいました……。止めてあげられなくて、ごめんなさい。わたし、本当に残念です……。`

## ツグミ(Iapetus)

**成功**(軽い反応 → 感心しても温度を上げない → 去り際の一言。名乗らない)
1. `[calm] あ、止まった。……へえ、やるじゃない。僕はそろそろ行くよ。`
2. `[calm] 止まったね。いいんじゃない。……それじゃ、僕は先に失礼するよ。`
3. `[calm] おや、終わったか。うん、上出来だったよ。……さて、僕は戻るかな。`

**失敗**(3文固定: ①「失敗」を言う ②聞こえているかを一度だけ軽く ③日常の用事を普通の言い方で)
1. `[calm] 失敗、だね。……聞こえてる? ……さて、お茶でも淹れようかな。`
2. `[calm] あー、失敗しちゃったか。そっち、聞こえてるかな。……洗濯物、取り込まなきゃ。`
3. `[calm] 今のは失敗だね。聞こえてる? ……そういえば、晩ごはん何にしようか。`

## モズ(Algieba)

**成功**(運びを褒める → 軽口を一言。軽口の方向は3本で変える)
1. `[relieved] 止まったな。最後まで段取り崩れんかったわ、ええ運びや。ほな、飯でも行こか。` (飲み食い)
2. `[warm] よっしゃ、きれいに収まったな。運びが丁寧やったで。ようやく肩の力、抜けるな。` (肩の力)
3. `[relieved] 解除完了や。最後まで段取りどおりやったな。お疲れさん、わしの出番はもう無いわ。` (労い。「お疲れさん」は3本中この1本だけ)

**失敗**(虚をつかれる三段: 静けさに反応 → 声が死ぬ → 次の手が出ない。入り方は3本で変える)
1. `[tense] ……あれ、えらい静かになったな。おーい、冗談きついで……。……次、何を言うたらええんや。`
2. `[tense] 今の音、なんや……? はは、笑われへんで、これ。……段取りが、狂うた。……どないしたら、ええんや。`
3. `[tense] 急に何も聞こえんようになったな。ドッキリか……? いや、……すまん、言葉が、出てけえへん。……次の手が、分からん。`

## 確認したい点

- **失敗 = 爆発の1種類**でよいか(成功3・失敗3は爆発のみを指す想定。他に「時間切れ」等を失敗に含める場合は別途追加)
- 流す1本の選び方は**ランダム**でよいか(同じ人が続けて遊ぶと重複しうる)
- 生成発話は**廃止してプリセットのみ**にするか、**生成が遅れたときのフォールバックとして残す**か
